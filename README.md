# Lifetime Capital Demo — PRD v1.1

Compiled static demo for Phase 1 routing and Phase 2 four Health Capital pages. No personal records are included. Financial amounts, FX, history and task fixtures are explicitly illustrative.

Health entry defaults to session memory; explicit consent enables unencrypted browser-local saving. No health records are uploaded to this repository or included in demo export. Not a clinical record system.

Open #/foundation/physical-performance, #/foundation/health-maintenance, #/foundation/reproductive-health or #/foundation/cognitive-energy. Ledger, Decision Log and Achievement are framework pages; their record workflows are later phases.
